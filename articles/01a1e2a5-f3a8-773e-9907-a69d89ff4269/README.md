造形には特に不具合はなく、臭いも確かに少ない。長時間閉め切ると独特の苦味のような臭いがしたので、換気は必要だった。ABSライクのような強度はなく、薄い板状のものではある程度しなる。

LPの記載事項について、労働安全衛生法・有機則・下水道法の記述は自己申告ベースではあるが公開情報間で矛盾はない。674物質は現在は改訂されている古い数字だが、2026年3月付のSDSでも表示・通知対象物質は「非該当」を維持している。ジャパニーズスタンダードアレルゲンについては、アクリル系レジンならふつう該当する物質を含まないので、根拠がこれ頼りならアレルギーフリーとするのは過言。皮膚刺激はSDSで警告されており、皮膚・呼吸器への感作性ほかもろもろデータなしなので、広範な安全を期待させるLPの書き方は過剰。とはいえClaudeによれば「オリゴマー主体ということで一般論としては一般的な水洗いレジンと比較して感作リスクは低めと推測できる」そうだ。

以前から適切な手袋やマスクや保護ゴーグルを装着し換気を行っているが、個人の住宅で行える対策には限界がある。エキマテについては、欠けているピースはあるものの、配慮を定量的な指標で示していること、低リスクと推測して矛盾のない特殊組成であることまでは事実である。今後も防護は続ける前提で、多段の安全策として、私には納得できる出費だと判断した。
